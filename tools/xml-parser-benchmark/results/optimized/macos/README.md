# Reviewed macOS implementations

The original measurements under `results/macos` are frozen. This directory contains separate optimized snapshots with source commits and library SHA-256 values in `source-manifest.json`. All builds use Release `-O3 -DNDEBUG` and C++23. The shared `XMLHandler` virtual change requires rebuilding both libraries and benchmark against the new headers.

The local Xerces control applies the same shared OpenMS fixes while retaining Xerces XML parsing. Its complete source patch against develop `77cccda7caf40b46a4919d33748450270eccd565` is `reproduce/xerces-control.patch`; it is not a fourth feature branch. Apply to a checkout at that base, commit, and set the local `experiment/xml-xerces-control` reference used by the build script.

The build driver uses a single dedicated `OpenMS-xerces-control` source checkout and an out-of-tree build, checking out each pinned backend and copying completed libraries to separate `snapshots-optimized` paths. Do not run another build or mutate those snapshots during timings. The driver passes the 25 affected class tests, one extra focused test for each prototype, shared benchmark smoke tests and the huge-array digest check before freezing each backend.

`screen.json` is a three-repetition preliminary selection check at 1/8 readers on large/plain and binary-zlib inputs; it is not mixed with the final five-repetition matrices. Final matrices use identical workloads, digest logic, inputs, repetition policy and runtime settings as the original experiment. The memory runner now includes both peak and retained RSS, making a duplicate macOS context-residency matrix unnecessary.

Reproduction scripts assume the task workspace layout and available parser dependencies described in the main README. First copy the Python files from `reproduce/` into that workspace root (or edit their `ROOT` constants); running them inside the published `reproduce/` directory would select the wrong workspace. Use a fresh dedicated source clone and pin its three local feature refs to the `source_commit` values in `source-manifest.json`: libxml2 `dc7ad95e1eb4fe72b37f59373416ccd339f39c75`, Expat `6ebf5ec649805d807c65c75e757bc21d4be2a3c9`, and pugixml `250dd47ef6af3879b1c2735041618c17e1ba1ccc`. Fetch the public feature branches first so those ancestor commits are available; later branch tips include additional reporting files. The build driver resolves local ref names, so leaving them at moving tips would change provenance. Recreate the local control branch with the supplied base-relative patch; its new commit metadata may differ, but its staged `git write-tree` must equal `cd9387209029839d243ae70532a90b4fb0cef294`. Provide the `OpenMS/` timed harness checkout, dependencies and generated inputs in the main README layout, adapting paths as needed. Then run `python3 build_optimized_macos.py`, `python3 run_optimized_macos.py --screen`, and `python3 run_optimized_macos.py`. Retain the frozen original artifacts separately. Boundary thermal/swap snapshots are not continuous monitoring.
